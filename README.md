# บึ้งไทย 3D — เกมจำลองการเลี้ยงแมงมุมทารันทูลา

เปิด `index.html` ในเบราว์เซอร์ได้เลย (หรือเปิด GitHub Pages)

## อิงหลักวิทยาศาสตร์
- 3 สายพันธุ์ไทย: บึ้งดำ (*Cyriopagopus minax*), บึ้งน้ำตาล (*Chilobrachys huahini*), บึ้งน้ำเงิน (*Cyriopagopus lividus*)
- เดิน 8 ขาแบบสลับทีละ 4 ขา (alternating tetrapod gait) ใช้ procedural animation + IK
- รับรู้เหยื่อจากแรงสั่นสะเทือน (วงสีส้ม) ย่องเข้าหาแล้วพุ่งกัด
- ดูเบียหนีและมุดดิน จิ้งหรีดกระโดดหนี
- ก่อนลอกคราบจะไม่กิน → นอนหงายลอกคราบ → เปลือกนิ่ม/เขี้ยวขาว ห้ามให้อาหาร
- สัตว์เลือดเย็น: อุณหภูมิมีผลต่อความเร็ว ออกหากินกลางคืน กลางวันหลบในโพรง
- จิ้มแมงมุม → ท่าขู่ยกขาหน้า หรือวิ่งหนีเข้าโพรง
- หินเป็นส่วนหนึ่งของพื้น: แมงมุมปีนได้ ตัวเอียงตามเนิน เหยื่อเดินชนหิน
- ขนแมงมุม (setae) หลายพันเส้น ชี้ไปทางปลายขา/ด้านหลัง
- ไฟตู้ (LED) แยกจากไฟอุ่น: เปิดไฟจ้า แมงมุมจะหลบในโพรงบ่อยขึ้น
- มอส เฟิร์น หญ้า ผนังหลังเปลือกไม้ก๊อก ฝุ่นลอยในแสง

## เวอร์ชัน 3 (ภาพระดับสูง)
- ไฟล์: `js/world.js` (ฉาก แสง ลายผิว), `js/spider.js` (โมเดล ขน แอนิเมชัน), `js/game.js` (ระบบเกม เอฟเฟกต์ภาพ), `js/facts.js` (ข้อมูลวิทยาศาสตร์)
- เอฟเฟกต์ภาพ: ชัดตื้นแบบมาโคร, bloom, ปรับสีภาพ, ปุ่มสลับคุณภาพภาพ
- แมงมุม: ขนนุ่มหลายหมื่นเส้นที่ไหวได้, ขา 4 ท่อน, ก้าวเป็นคลื่นจากขาหลังไปหน้า, ท้องแกว่งตามแรงเหวี่ยง
- ขอนไม้กลวงจริง (เปลือก เนื้อไม้ วงปี), มอส เฟิร์น ใบไม้แห้ง กรวด กิ่งไม้
- ชื่อวิทยาศาสตร์ปรับตาม World Spider Catalog 2026: *Melopoeus minax*, *Melopoeus lividus* (เดิม Cyriopagopus)

## เวอร์ชัน 4 (หิน หญ้า ขาไม่ทะลุ)
- หินใหม่: รูปทรงแตกเป็นเหลี่ยม มีรอยแตก ชั้นหิน มอส ไลเคน ลายหินแกรนิตไม่ยืดตามด้านข้าง ยังปีนได้เหมือนเดิม และเพิ่มหินก้อนเล็กเป็นกลุ่ม
- หญ้าใบกว้างเป็นกอ และพุ่มใบกลม: ใบเป็นฟิสิกส์ แมงมุมและเหยื่อเดินแหวกได้ ใบเด้งกลับ และไหวตามลม (หญ้าเส้นเล็กเดิมก็แหวกได้ด้วย)
- ขาไม่ทะลุหิน: เลือกจุดวางเท้าที่เอื้อมถึงจริง ขาส่วนปลายวางตามผิวหิน ข้อต่อถูกดันออกจากหิน ตัวไม่จมหิน

## เวอร์ชัน 5 (ทุ่งหญ้า แมงมุมพูดได้ ดูแลอัตโนมัติ)
- ทุ่งหญ้าสั้นหนาแน่นแบบเกม Zelda มีคลื่นลมพัดผ่าน เดินแหวกได้ · กอหญ้าพุ่มลดเหลือ 6 กอ · ใบไม้แห้ง/กิ่งไม้ขนาดสมจริงขึ้น
- จิ้งหรีด/ดูเบีย: ขาเป็นข้อต่อจริง เดินสลับ 3 ขา หนวดกวาดไปมา จิ้งหรีดย่อตัวก่อนกระโดดและร้องตอนกลางคืน ดูเบียมุดดินลง-ขึ้น เหยื่อที่โดนกัดดิ้นแล้วค่อยๆ นิ่ง
- แมงมุมเดินแบบหยุดๆ เดินๆ เหมือนจริง
- สมุดบันทึกใช้เวลาจริงของเครื่อง · แมงมุมพูดตามอารมณ์/สถานการณ์ (ติดเบียวสไปเดอร์แมน) มีบอลลูนคำพูดเหนือตัว
- หิวจัด → ปล่อยเหยื่อให้เอง 1 ครั้ง · ความชื้นต่ำมาก → พ่นน้ำเอง 1 ครั้ง
