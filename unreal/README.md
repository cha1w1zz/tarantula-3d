# บึ้งไทย 3D → Unreal Engine 5

ขั้นแรกของการย้ายเกมไป Unreal: เอา **ฉากทั้งหมด** (ตู้ สวน เมืองร้าง แมงมุม เหยื่อ คน) ไปเปิดใน Unreal
ไม่ต้องลง Visual Studio ไม่ต้องเขียน C++

## ต้องมี
- Unreal Engine 5.1 ขึ้นไป (ฟรี จาก Epic Games Launcher)

## วิธีทำ (ประมาณ 5 นาที)
1. **เอาไฟล์ออกจากเกม** — เปิดเกม → ⚙ตั้งค่า → กด **📦 ส่งออกไป Unreal (.glb)**
   ได้ไฟล์ `tarantula-scene.glb` ในโฟลเดอร์ Downloads (แมงมุมจะโตแค่ไหน ท่าไหน ก็ได้แบบนั้นในไฟล์)
2. **สร้างโปรเจกต์ใน Unreal** — Games → Blank → เลือก **Blueprint** (ไม่ใช่ C++) → Create
3. **เปิดปลั๊กอิน Python** (ครั้งเดียว) — Edit → Plugins → ค้น `Python Editor Script Plugin` → ติ๊ก → Restart
4. **สร้างฉากว่าง** — File → New Level → **Empty Level**
5. **รันสคริปต์** — Tools → **Execute Python Script...** → เลือก `unreal/import_tarantula.py`
   สคริปต์จะนำเข้าโมเดล วางลงฉาก ใส่แดด ท้องฟ้า หมอก และกล้องให้เอง
6. กด **G** เพื่อดูภาพแบบไม่มีเส้นช่วย · คลิกขวาที่ `Tarantula_Camera` ใน Outliner → **Pilot** เพื่อดูผ่านกล้อง

### ไม่อยากใช้สคริปต์?
ลากไฟล์ `.glb` ใส่ช่อง Content Browser → Import → แล้วลากโมเดลทั้งหมดลงฉาก (ตั้งตำแหน่ง 0,0,0 ทุกชิ้น)

## ที่ได้ / ยังไม่ได้
| ได้แล้ว | ยังไม่ได้ (ขั้นต่อไป) |
|---|---|
| รูปทรงทุกอย่าง ขนาดจริง (1 หน่วยในเกม = 1 เมตร) | แมงมุม/คนยังขยับไม่ได้ (เป็นรูปปั้น) |
| สี + ลายพื้นผิวส่วนใหญ่ | น้ำ หญ้าไหว แสงลำ ใยแมงมุม (ใช้ shader พิเศษ ต้องทำใหม่ใน Unreal) |
| แยกโฟลเดอร์ World / Spider / Human / Prey | ระบบเกม: หิว ลอกคราบ ไล่ล่า เฮลิคอปเตอร์ ปุ่มภาษาไทย |

## ถ้าเจอปัญหา
- **ไม่มีเมนู Execute Python Script** → ยังไม่ได้ทำข้อ 3
- **"ไม่เจอ tarantula-scene.glb"** → วางไฟล์ไว้ข้าง `import_tarantula.py` หรือใน Downloads
- **ช้าตอนนำเข้า** → ปกติ ฉากใหญ่ (หลายแสนสามเหลี่ยม) รอ 1–3 นาที
- อื่น ๆ → เปิด Window → Output Log แล้วส่งข้อความสีแดงมาให้ Claude ดู
